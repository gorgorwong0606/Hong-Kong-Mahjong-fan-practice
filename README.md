# 港式台牌計番練習

系統出一副已經食胡嘅台牌。你睇番數表計總番，輸入數字，對答案。錯咗會列出每一項番，等你睇自己漏咗咩。

只跟這張番數表（台灣麻雀 Mau），唔用第二套計法。畫面已經寫明圈風、門風、自摸定出沖、聽牌、牌牆剩餘、食胡位置。暗牌拆好組，跟畫面嗰組計。

## 運行

```bash
npm install
npm run dev -- -p 4317
```

打開 [http://127.0.0.1:4317](http://127.0.0.1:4317)。

```bash
npm test
```

## 計法備註

- 正花：東春梅、南夏蘭、西秋菊、北冬竹。春夏秋冬齊加一台花。梅蘭菊竹齊只收一台草 3 番，唔再逐隻計。
- 無字花、無字花平胡、門清自摸、門清聽牌，已包括細項，唔再疊加。
- 其他番加完剛好 1 番：出沖變雞胡 25，自摸變鴨胡 13。
- 地胡、人胡唔計門清。天聽就門清另計。
- 小六姊妹已包括清一色同對對胡。清么唔計兄弟、老少碰。
- 三色連碰小、大每手最多各一次。四歸三表內無，所以唔計。
- 花胡、七搶一、雪上加霜、圍骰呢類即時牌局，同間間胡，練習暫時唔出。
