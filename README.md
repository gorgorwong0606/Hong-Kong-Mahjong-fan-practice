# 港式台牌計番練習

系統出一副已經食胡嘅台牌。你睇番數表計總番，輸入數字，對答案。錯咗會列出每一項番，等你睇自己漏咗咩。

只跟這張番數表（台灣麻雀 Mau），唔用第二套計法。畫面寫明圈風、門風、自摸定食出、聽牌。出街嘅牌喺上面一行，手牌喺下面一行，食胡嗰隻打橫，組牌唔再標順、碰、暗刻。七只內、十只內唔計。

## 運行

```bash
npm install
npm run dev -- -p 4317
```

打開 [http://127.0.0.1:4317](http://127.0.0.1:4317)。

## 長期公開網址

用 GitHub Pages。免費，網址係 `https://你的名字.github.io/...`，GitHub 自動開 HTTPS。呢個站冇登入、冇資料庫、冇密碼，只係計番，適合咁放。

1. 喺 GitHub 開一個新 repo，揀 Public。免費 Pages 要公開 repo。網站本身係公開，所以程式碼一齊公開先免費。
2. Repo 名叫 `你的名字.github.io`，網址就係 `https://你的名字.github.io/`。用其他名，網址就係 `https://你的名字.github.io/repo名/`。
3. 將呢個專案推上去，分支用 `main`。
4. 去 repo 嘅 Settings → Pages → Build and deployment，Source 揀 GitHub Actions。
5. 等 Actions 跑完。網址會顯示喺該次部署上面。

唔好將 token、密碼放進 repo。臨時隧道會過期，長期用就以呢條 `github.io` 為準。

```bash
npm test
```

## 計法備註

- 正花：東春梅、南夏蘭、西秋菊、北冬竹。春夏秋冬齊加一台花。梅蘭菊竹齊只收一台草 3 番，唔再逐隻計。
- 無字花、無字花平胡、門清自摸、門清聽牌，已包括細項，唔再疊加。
- 其他番加完剛好 1 番：出沖變雞胡 25，自摸變鴨胡 13。
- 地胡、人胡唔計門清。天聽就門清另計。
- 小六姊妹已包括清一色同對對胡。清么唔計兄弟、老少碰。
- 明龍已包括同門老少，唔再加 3 番。另一門嘅老少照計。老少碰唔受影響。
- 坎坎糊（間間胡）200：五組暗刻或暗槓加眼，而且門清自摸。已包括門清、自摸、五暗刻、對對胡。出沖五暗刻仍然另計。
- 大三元已包括中、發、白三組箭刻，唔再逐組加 2 番。小三元兩組箭刻另計。大四喜風刻仍然另計。
- 三色連碰小、大每手最多各一次。四歸三表內無，所以唔計。
- 花胡、七搶一、雪上加霜、圍骰呢類即時牌局，練習暫時唔出。
